# 2026-06-30 | ae-sdd v3.6.0 - RA 实现视角七要素 + G-RA-6

## 背景

本次需求分析实测暴露 RA 能力缺陷：RA 只做了产品/流程层面的改写，没有站在实现角度挖清数据源、数据流、字段定义、不变量、现有实现复用、高成本设计反驳和开发者疑问，导致后续 DR 仍需要大量猜测，无法为 Story/Task/Coding 打下可靠事实基础。

## 行为变化

- RA 文档缺少实现视角七要素时，`ae-sdd gates check --only G-RA-6` 会阻断。
- `ae-sdd ra-implementation-scan --root <dir>` 可单独扫描 RA 文档实现视角完整性。
- 该门禁与 G-RA-5 正交：G-RA-5 查机械派生深度，G-RA-6 查实现落地信息是否足够支撑 DR/Coding。
