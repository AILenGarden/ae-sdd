## 触发原因

- 用户要求对 ae-sdd 做全盘 bug 扫描，实测发现 25 个测试失败（红灯状态）。
- v3.9.13（416db5e）废弃项目级 `.ae-sdd/state.json` 作为 state 源（work_item_context.py 头注释明示"intentionally not a fallback because it leaks state across concurrent sessions"），改为 task-scoped `.auto-engineering/<work-item>/state.json`，但大量测试 fixture 仍写旧镜像 -> state 解析失败 -> 门禁逻辑未被真正触达。
- v3.9.20 G-STORY-CTX 收紧（取消小/微豁免 + 新增 standardsRef 真已引用门禁），context_gates fixture 未跟上。
- v3.9.22 发版时版本号三处（SKILL.md/paths.py/README）未同步 bump，导致 UC-01/UC-07 报红。
- 5 个 shell 入口脚本自 v3.0.1 跨平台化起就存在 `py -3` 引号 bug（与 .ps1 版的正确数组 splatting 形成对比）。

## 影响范围

- 代码改动：6 处确定性 bug 修复（paths/gates/assets_index/update_graph/5 脚本/post-commit）。其中 gates.py 三元运算符修复改善了 BLOCKER 诊断信息质量，assets_index 修复了多文件项目 `assets stats` 崩溃，update_graph 修复了 drift kind 标签准确性，post-commit 修复了分发闭环状态判定反转。均不改变门禁拦截语义。

- 版本号：推进到 3.9.22（UC-01 三处一致 + .adapter.lock 对齐）。
- 无破坏性变更：用户/下游无需适配。入口脚本修复仅影响 Windows 仅装 py launcher 的回退路径（之前崩溃，现在可用）。
