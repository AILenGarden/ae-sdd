# 2026-06-24 | ae-sdd v3.2.2 - Toolset Layer P0

## Summary

ae-sdd now has a first Toolset Layer slice. This complements Harness:

- Harness controls whether the Agent may use tools.
- Toolset commands collect auditable project evidence.
- Skills decide when each toolset is mandatory.
- Gates can consume structured tool output.

## Mandatory Memory Rule

For associated nodes:

```bash
ae-sdd memory enter --phase <phase> --story <STORY-ID>
# node work
ae-sdd memory write --phase <phase> --story <STORY-ID> --summary "..."
ae-sdd memory exit --phase <phase> --story <STORY-ID>
```

`memory exit` fails when no write happened after the latest `enter`.

## doc-to-instance / migration tool check

The existing document migration tool is `scripts/migrate-docs.mjs`, backed by
`document-storage-skill.md`'s `migrate_old_docs()` contract.

This Toolset Layer update does not change old-document path mapping, document
versioning, or `ae-sdd-doc/` migration behavior. No update is required for
`migrate-docs.mjs` in this release.
