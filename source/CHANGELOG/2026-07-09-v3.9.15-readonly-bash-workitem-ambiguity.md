# 2026-07-09 | ae-sdd v3.9.15 - 只读 Bash 不受 work-item 歧义阻断

## Summary

life 项目存在多个 `.auto-engineering/*/state.json`，`gate-intercept` 为避免 A/B 会话串任务，会拒绝隐式推断 active work-item。原实现先解析 work-item 再判断只读 Bash，导致 `echo test` 这种无副作用探测命令也被 `AmbiguousWorkItemError` 锁死。本次把只读 Bash 判断前移到 state 解析之前，并细分安全 echo/printf：无重定向的单条 `echo test` 放行，`echo test > out.txt` 仍不视为只读。

## Changes

| Area | Change |
|---|---|
| `tools/lib/gate_intercept.py` | 在 `check_intercept()` 中将只读 Bash 快速放行前移，避免多 work-item 歧义锁死只读命令 |
| `tools/lib/gate_intercept.py` | `_is_readonly_bash()` 增加 `>` / `<` 重定向拦截，并允许无重定向单条 `echo` / `printf` |
| `tools/lib/gate_intercept.py` | 修复 Python 3.15 对 docstring 中 `d:\tmp\` 的 invalid escape `SyntaxWarning` |
| `tools/tests/test_gate_intercept.py` | 增加 `echo test` 放行、重定向 echo 拦截、多 work-item 歧义下只读 Bash 放行的回归测试 |

## 触发原因

- 用户在 `D:\Item\life` 中测试 `Bash echo test` 仍被 `Hook PreToolUse:Bash denied this tool` 拒绝。
- 实测 hook 返回原因是：life 同时存在 `cs-ai-STORY-003-BE`、`cs-ai-STORY-005-BE`、`Story-004` 三个 work-item state，gate 为防串任务拒绝隐式选择。
- 只读 Bash 的安全判断顺序错误，导致无副作用探测命令被状态歧义误拦。

## 影响范围

- 涉及运行时逻辑：PreToolUse `Bash` hook。
- 不放松写入类保护：`echo test > out.txt`、`mvn test` 等非只读 Bash 仍会因多 work-item 歧义被拦，直到用户显式选择 work-item 或启用快速通道。
- 不改变 `state write` 的 work-item 隔离策略，不恢复全局 `.ae-sdd/state.json` mirror。
- 能力设计文档不受影响；实现架构文档已覆盖 gate/hook 作为 CLI 权威，无需新增章节。

## 验证方式

- `python -m pytest tools/tests/test_gate_intercept.py tools/tests/test_fixes_v14.py::TestBashReadonlyPrefixesExpanded -q`：128 passed。
- life 真实 hook 复测：`Bash echo test` 返回 `{}` 且 exit 0。
- life 真实 hook 复测：`Bash "echo test > out.txt"` 和 `Bash "mvn test"` 仍返回 `permissionDecision=deny`，原因是多个 work-item state 歧义。
