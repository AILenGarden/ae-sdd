## Summary

前一轮诊断发现 ae-sdd 项目"能脚本化的主体部分基本都已脚本化"，但存在 3 个文档自认的明确缺口
+ 1 处仓库根残留未自动化清理。本次按"全做，按顺序来"逐项补齐：
1. `ae-sdd init` 命令未挂 CLI（UC-03 历史遗留 warn）——`init.py` 实现已就绪但 CLI 未注册；
2. `source/CHANGELOG/_template.md` 缺失——`ae-sdd-update-skill.md:298` 承诺但文件不存在；
3. 版本号 bump 未脚本化——UC-01 只校验三处一致，提升版本号本身靠手工改；
4. 仓库根 `nul` / `plugins/ae-sdd.bak.*` 残留——无清理逻辑。

本次补齐后，UC-03 历史遗留 warn 中 `init` 项清零，版本号同步闭环（校验+操作双轨），
CHANGELOG 模板承诺兑现，dev-sync 前自动清理仓库根残留。

## 触发原因

- 用户要求检查"能脚本化的部分是否都已脚本化"，诊断出 3 个文档自认缺口 + 1 处残留。
- 用户确认"全做，按顺序来"，4 个缺口逐项落地。
- UC-03 `HISTORICAL_UNIMPLEMENTED` 中 `init` 是唯一有现成实现（init.py）却未挂 CLI 的项，性价比最高先补。
- UC-01 长期只有"校验侧"无"操作侧"，版本号三处手工同步易漏（虽有 UC-01 兜底），bump 命令闭环。
- `ae-sdd-update-skill.md:298` 承诺 `CHANGELOG/_template.md` 但文件缺失，模板承诺落空。
- 仓库根 `plugins/ae-sdd.bak.20260617170054/` 残留无清理逻辑（install.py prune 只管安装目标侧）。

## 影响范围
