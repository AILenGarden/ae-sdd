### 6.4 gate_intercept.py 核心设计

```
Phase → PHASE_PERMIT 映射（10 个 phase，frozenset 许可工具）
  - initialized / dr-generated / story-generated / story-reviewed / task-generated：只允许 Write + Edit
  - task-reviewed / coding / test-running：允许 Write + Edit + Bash
  - code-reviewed：只允许 Write + Edit
  - completed：空集（全拒）

只读放行：Read / Glob / Grep / TodoWrite / TodoRead / LS / Cat / AskUserQuestion
Bash 只读命令放行：cat / ls / find / grep / echo / pwd / git status / git log / git diff / ae-sdd CLI
无 .ae-sdd/ → 放行（不影响非 ae-sdd 项目）
快速通道：ae-sdd-quick / 走快速通道 → 放行（或环境变量 AE_SDD_QUICK=1）
拒绝时：stdout exit 1，stderr 输出结构化错误 + 下一步建议
```

### 6.5 init-hooks 行为

`ae-sdd init-hooks <project-dir>` 在项目 `.claude/settings.json` 写入：

```json
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Write|Edit|Bash",
      "hooks": [{
        "type": "command",
        "command": "ae-sdd gate-intercept --tool \"${TOOL_NAME}\" --bash-command \"${BASH_COMMAND:-}\""
      }]
    }]
  }
}
```

- 幂等：已存在 `Write|Edit|Bash` matcher 时跳过（加 `--force` 覆写）
- `scripts/init.py` 在 init 完成后自动调用，失败时降级为 warn（不中断 init 流程）

### 6.6 build_dist.py 更新

- `HARNESS.md` 和 `harness/` 在分发包中默认包含（不在 EXCLUDE_DIRS）
- `docs/` 整体排除，但 `docs/ae-sdd-conventions.md` 通过 `DOCS_KEEP` 白名单保留
- tar 路径版本（主流程）和 fallback working tree 版本均已更新
- 验证阶段新增 HARNESS.md / harness/ 存在性检查（warn，不致命）

## 不承诺"永不再犯"

v3.1 是软约束纪律加固,**不承诺"永不再犯"**。原因:

- LLM 训练分布、上下文长度、用户表达差异都会影响 AI 决策
- 唯一能"永不再犯"的方案是 L4 hook 强制(已在 v3.2 评估项)
- SKILL 是软约束,无法强制 AI 行为

**务实目标**:再犯率从 ~50% 降到 ~5%,失职时**早期发现 + 显式标注 + 留追溯**。
