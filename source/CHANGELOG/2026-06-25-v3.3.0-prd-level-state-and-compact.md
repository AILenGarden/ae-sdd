# 2026-06-25 | ae-sdd v3.3.0 - PRD 级状态机 + 流程级 compact

## Summary

v3.2.x 之前 ae-sdd 的状态跟踪粒度是 Story 级（`.auto-engineering/{STORY-ID}/state.json`），用户在 PRD（产品需求）完成时缺乏自动化判定与收尾流程——所有 Story 完成后是手动判断"PRD 是否能收尾"，跨 Story 残留风险手工追踪，handoff 到下个 session/PRD 时容易丢上下文。

本次 v3.3.0 引入 **PRD 级状态机 + 流程级 compact** 体系：在 Story 级之上加一层 PRD 级 `.auto-engineering/{PRD-ID}/state.json`（聚合 Story / 跨 Story 依赖 / 残留风险 / sizeBudget / 4 层 AND 闸 / prdStatus），并打通 Mavis / Claude Code / Codex 三大 runtime 的 compact 适配层。Codex 部分因 hook 协议待验证（Codex PoC），先用 PoC-first 路径（30 分钟查清 hook 协议）替代。
