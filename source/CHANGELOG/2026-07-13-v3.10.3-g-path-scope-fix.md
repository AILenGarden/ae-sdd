# 2026-07-13 | ae-sdd v3.10.3 - G-PATH scope and harness closure

## Summary

This patch release hardens G-PATH path ownership in two boundaries: canonical document-storage source/runtime fallbacks are exempt only by strict relative path, and project-side scanning is limited to declared memory inputs instead of Review/generation drafts. The official harness adapter outputs were regenerated after the source update.
