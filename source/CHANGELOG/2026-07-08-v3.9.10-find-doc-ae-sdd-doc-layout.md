# v3.9.10 - 门禁路径 bug 修复：find_doc/list_docs 覆盖 document-storage 新布局 ae-sdd-doc/

## 摘要

修复门禁 CLI 在项目使用 `document-storage-skill` 统一目录 `ae-sdd-doc/` 存放文档时无法自动通过的路径 bug。

**根因**：`paths.find_doc` / `paths.list_docs` 原只搜 deprecated 旧路径 `design/` + 项目根 + `task/`，未覆盖
document-storage 新布局 `ae-sdd-doc/{Category}/`。当项目按新布局存放文档时：
- G-02（Story）/ G-04（TestCase）/ G-07（CodingPlan）/ G-05（Task）找不到文档 -> 误判 block 失败；
- 上下文准入门禁（G-STORY-CTX / G-TESTCASE-CTX / G-TASK-CTX / G-DR-CTX 等）同样因 `paths.find_doc`
  返回 None -> 误判上下文未加载。

报告类门禁 G-10/G-11/G-12 已通过 `_find_report_doc` + `_doc_search_roots` 正确覆盖新布局，但
Story/TestCase/CodingPlan/Task 四类设计文档门禁漏掉了同样处理。

**修复策略**：把多根搜索能力下沉到路径 SSOT（`paths.py`），`find_doc` / `list_docs` 内部同时搜
旧路径 + `ae-sdd-doc/`（rglob 兜底），**签名向后兼容**，所有调用方零改动即修复。

## 变更

### tools/lib/paths.py

**新增 `doc_search_roots(project_dir) -> list[Path]`**

从 `gates._doc_search_roots` 逻辑提炼为 paths 模块公共函数（路径 SSOT）。返回去重后的搜索根列表
`[project_dir, docWorkspace]`，docWorkspace 经 `resolve_doc_workspace` 解析（assets §1
docWorkspacePath > gitPath 回退）。无 `.ae-sdd/config.yaml` 或无 projectKey 时仅返回 `[project_dir]`
（向后兼容，现有测试无 .ae-sdd 仍通过）。

**改造 `find_doc(project_root, story_id, suffix)`**

| Before | After |
|--------|-------|
| 只搜 `design/{story_id}{suffix}` + `{root}/{story_id}{suffix}` | 额外搜 `ae-sdd-doc/` 下 rglob `{story_id}{suffix}`（覆盖 Story/Test/Coding/Task 等所有 category 子目录 + iterations/） |

搜索顺序：旧路径优先（design/ > 项目根 > ae-sdd-doc/），保持历史项目行为不变。root 取自
`doc_search_roots`（项目根 + docWorkspace），保证 docWorkspace 分离项目也能命中。

**改造 `list_docs(project_root, story_id, suffix)`**

| Before | After |
|--------|-------|
| 只搜 `task/{story_id}{suffix}` | 额外搜 `ae-sdd-doc/Task/{story_id}/{story_id}{suffix}`（新布局），跨根去重 |

**版本号**：`MASTER_VERSION` 3.9.9 -> 3.9.10（patch，Bug 修复）

### tools/lib/gates.py

**`_doc_search_roots` 委托 paths（DRY）**

| Before | After |
|--------|-------|
| 自拼 docWorkspace 解析逻辑（read_config + resolve_doc_workspace + _dedupe_paths） | 委托 `paths.doc_search_roots(project_dir)` 一行 |

行为不变，`_find_report_doc` 等调用方零影响。消除 gates 内与 paths 重复的路径解析逻辑。

## 影响

- **无破坏性变更**：`find_doc` / `list_docs` 签名不变，新增候选路径不删除旧路径，现有 `design/` 项目零影响。
- **性能**：rglob 仅在 `ae-sdd-doc/` 目录存在时触发；无该目录的旧项目走旧路径，无额外开销。
- **SSOT 一致性**：修复后 `find_doc`（设计文档查找）与 `_find_report_doc`（报告查找）统一走
  `paths.doc_search_roots`，消除 gates.py 内重复的路径解析逻辑（DRY）。
- **不改 `document_storage.py`**：路径模板 SSOT 不动，仅修查找侧。
- **受益门禁**：G-02 / G-04 / G-05 / G-07 / G-14 / G-CODEPLAN-SRC / G-DOC-CONSISTENCY /
  G-STORY-CTX / G-TESTCASE-CTX / G-TASK-CTX / G-DR-CTX（所有 `paths.find_doc` / `paths.list_docs` 调用方）。
- **版本号**：v3.9.9 -> v3.9.10（patch，Bug 修复）
