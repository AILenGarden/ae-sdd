- **L1（CODING ENTRY CONTRACT）**：定义在 `source/HARNESS.md:28-47`，已随 distribute.py 分发到三家 skill runtime，触发语义已是"改动级加载"。
- **L2（会话级纪律）**：散落在三家全局指令文件（ZCode AGENTS.md / Codex AGENTS.md / Claude CLAUDE.md），各自手写、措辞分化、无锚点、不在分发链内，已漂移。

## 变更

### 1. 新增 SSOT 母版 `source/L2-DISCIPLINE.md`

ae-sdd 仓库内唯一的 L2 纪律权威源。中英双语（SECTION:zh / SECTION:en），注入器按 agent 语言切片。

- 触发语义统一为"改动级加载"（与 L1 一致）：删 ZCode"首轮必须"+"无例外"绝对化措辞，改为"在制定实现计划或首次写入前加载并调用 ae-sdd"
- 纪律正文以 ZCode 完整骨架为蓝本（顺序红线/禁止跳链/四上下文强制加载/非仓库工程目录判定/门禁 G-* 引用/harness 审批隔离）
- 补入 Codex 独有强约束（反向注入 SSOT）：fail-closed + 反作弊 + 环境不可用处置 + `/ae-sdd-quick` 仅用户可选
- 红线条款 11 纳入（redline11:zh / redline11:en），Claude bootstrap 时补进红线表

### 2. 扩展 `tools/lib/distributor_registry.py`

- `_KNOWN_AGENTS` 每个条目新增 `l2_global_file` / `l2_language` 字段
  - claude: `~/.claude/CLAUDE.md` / zh
  - codex: `~/.codex/AGENTS.md` / en
  - zcode: `~/.zcode/AGENTS.md` / zh
  - hermes / harness: None（无全局文件，跳过）
- `DistributorEntry` dataclass 新增对应字段，`from_dict`/`to_dict` 同步
- `load_registry` 加迁移逻辑：旧注册表条目自动从 `_KNOWN_AGENTS` 回填缺失的 l2 字段

### 3. 新增注入器 `scripts/l2_inject.py`

纯 Python（零外部依赖），复用 harness-adapter 四件套设计（幂等/diff-aware/备份/审计）。

- **锚点区间替换**：`<!-- BEGIN ae-sdd-l2-ssot -->` ... `<!-- END ae-sdd-l2-ssot -->`，只替换锚点之间内容
- **锚点外零改动校验**：落盘后用 difflib 校验锚点外区域与备份字节一致，不一致回滚报错
- **diff-aware skip**：SSOT 内容 hash 未变则跳过（幂等）
- **bootstrap 模式**：首次落盘识别现有 ae-sdd 段落边界（三家各自标题模式），dry-run 预览 + apply 执行，不在 post-commit 自动链路
- **Claude 红线补丁**：bootstrap 时在红线表条款 10 后插入条款 11 + 同源注释（锚点区外，单独标记）
- **备份可回滚**：每次注入前 `.bak.<ts>`，保留最近 3 份，`--rollback` 可恢复

### 4. 挂载 `scripts/distribute.py`

在 `_ensure_l2_global_registry_skeleton` 之后调用 `inject_all`（失败不阻断分发链）。bootstrap 不在自动链路，首次落盘需手动 `--bootstrap --apply`。

### 5. 测试 `tools/tests/test_l2_inject.py`

21 项测试全通过，覆盖：SSOT 语言切片、锚点区间替换（锚点外零改动断言）、diff-aware skip、bootstrap 段落边界识别（三家）、备份回滚、harness/hermes 跳过、Claude 红线补丁。
