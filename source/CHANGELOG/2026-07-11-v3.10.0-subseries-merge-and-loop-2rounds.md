# 2026-07-11 | ae-sdd v3.10.0 - 子系列合并 + review-loop 3轮降2轮

## Summary

在 v3.10.0 砍 Task phase 的基础上进一步精简：① 将 Story 和 TestCase 两个子系列的 generate+review 两个独立 phase 合并为一个 phase（内部仍由 agent 先调 generate skill 再调 review skill，loop 退出逻辑不变）；② 将 review-loop 的"连续无新增退出阈值"从 3 轮降为 2 轮，循环上限同步从 3 降为 2。

合并后大链从 11 phase 降至 9 phase，中链从 10 降至 8。review-loop 2 轮在审漏风险与流程效率间取得平衡，显著缩短单 Story 实现耗时。

## Changes

| state.py | PHASE_FLOWS 移除 story-reviewed/testcase-reviewed（大/中链）；story-generated/testcase-generated 各自 = generate+review loop 完成 |

| SKILL.full.md | 状态机子链大(9)/中(8)；TodoWrite 清单 Story/TestCase 步骤合并为 loop；review-loop 文案 3轮->2轮 |

## 触发原因

- 用户反馈：3 轮 review-loop 在单 Story 8 小时场景下过度冗余，2 轮已足够收敛缺陷且显著缩短流程
- 子系列 generate+review 拆成两个 phase 增加了状态机跳转次数，合并为 loop 减少不必要的 phase 切换

## 影响范围

- phase 链缩短：大 11->9、中 10->8（小/微不变）
- review-loop 退出阈值全局从 3 降为 2（EXIT_DRY_THRESHOLD + MAX_ROUNDS）
- skill 不合并：story-generate/story-review 仍是两个独立 skill，在同一 phase 内由 agent 编排
- G-03 门禁适配：story-generated 加入 PHASE_PAST_STORY_REVIEW（进入 = review 已过）
