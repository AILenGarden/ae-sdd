# 2026-06-25 | ae-sdd v3.4.1 - 分发闭环加固（post-commit hook 自动同步）

## Summary

v3.4.0 之前的根本问题：**母版仓 commit 后没有任何自动触发器** 把更新推到 `dist/ae-sdd/` → `~/.claude/skills/ae-sdd/` → `~/.zcode/skills/ae-sdd/` → `harness/.harness/agent.md` → mavis mount，**全靠开发者主动跑 `dev-sync.sh`**。结果：v3.2.x 系列 12 个 commit 期间没人跑 → `harness/.harness/agent.md` 停在 v3.1.2、已装 SKILL 停在 v3.2.3、`.adapter.lock` 漂移到 3.3.0，**4 个世界全断**。

v3.4.1 解决方案：**`.githooks/post-commit` hook** 在 `git commit` 完成后 0 秒自动跑分发链，hook 自身入仓 + `git config core.hooksPath = .githooks` 让它跟仓库一起分发；同时新增 3 条反向探测（`ae-sdd health master-freshness` / `prompt_inject` master-freshness 注入 / `init.py` 写 master.version），让"已装 vs 母版"漂移可观测；新增 UG-11 + UC-07 把"分发闭环"纳入更新图谱 + 自动检查。

## 触发原因

用户硬反馈"ae-sdd 的问题很多，究竟有没有作为一个 harness 注入到我们的 Agent 之中？流程频频失效"。Phase 1 调研发现 **4 个世界漂移** + **9 个版本号差** + **0 个自动触发器**——这是 v3.4.0 设计缺陷，不能靠文档/口头约束修补。修母版分发闭环是 P0 必修。

## 影响范围

- **正向**：未来 ae-sdd 母版的任何 commit → 0 秒内自动同步到 `~/.zcode/skills/ae-sdd/`（已装 SKILL）+ `harness/.harness/agent.md`（mavis 看到），杜绝 v3.4.0 的 8 个版本漂移
- **反向**：`ae-sdd health` 多 1 项 master-freshness 检查；`prompt_inject` 注入块多 1 行（已装落后时）；`init.py` 写 `master.version` 时不再硬编码 3.0.0
- **风险**：post-commit hook 在 Windows 上路径或权限有问题时单步失败，已用 `set -u`（不开 `-e`）+ 每步 try-catch 容错 + 不阻断 commit 兜底

## 验证方式

```bash
cd D:\Item\ae-sdd

# 1. UC-07 分发闭环检查
ae-sdd update-check
# 应看到 7/7 全 PASS（含新增 UC-07）

# 2. master-freshness 健康度
ae-sdd health
# 应看到 9 项，第 9 项 master-freshness 显示 "全部一致"

# 3. 分发闭环单元测试
python tools/tests/test_distribution_closure.py
# 应看到 9/9 passed

# 4. 真实 commit 触发（可选，会跑完整 5 步分发链）
echo "" >> source/SKILL.md
git add source/SKILL.md
git commit -m "test: post-commit hook 真实触发"
# 应看到 4-5 行 "✅" 输出
```
