# 2026-07-03 | ae-sdd v3.8.2 - Compact Memory Write Contract

## Summary

将 memory 写入从“自由文本摘要”收紧为 compact context index。Agent 不再只靠提示词自觉写短记忆；`ae-sdd memory write` 现在在写入端强制校验摘要长度、证据、kind 和单行格式，防止 memory 变成长期 token 债务。

## Changes

| Area | Change |
|---|---|
| `tools/lib/memory_store.py` | 新增 compact memory 校验：L1<=180 字符、L2<=140、L3<=120；L1+ 必须带 evidence；L2/L3 禁 `kind=observation`；拒绝多行、代码块、超长 evidence/tag。 |
| `tools/bin/ae-sdd` | `memory write --summary/--kind/--evidence` help 文案同步 compact 预算和 evidence 要求。 |
| `tools/lib/prompt_inject.py` | memory 注入改为 `MEMORY compact` 短格式；读取时先过滤非 L0 memory，再取最近窗口，避免 L0 enter/exit/scratch 挤掉 L1/L2 记忆。 |
| `source/skill-fallbacks/skills/cross-cutting/memory-management-skill.full.md` | 明确 Agent 写入模板、允许 kind、好/坏 memory 示例和 compact 预算。 |
| `source/standards/toolsets/memory-layering.md` | 标准层补充 compact memory 规则：memory 是上下文索引，不是日志、报告或复盘。 |
| `tools/tests/test_memory_gate.py` / `tools/tests/test_toolsets.py` | 覆盖 L1 evidence 强制、L0 scratch 放行、摘要长度限制、L2 observation 拒绝、L0 不挤占注入窗口。 |

## Behavior

推荐写法：

```bash
ae-sdd memory write --phase coding --story STORY-001 --kind fix --summary "UserMapper query now filters by tenant_id to prevent cross-tenant reads." --evidence src/main/resources/mapper/UserMapper.xml:31
```

以下写法会被拒绝：

- L1/L2/L3 无 `--evidence`
- L1 超过 180 字符、L2 超过 140 字符、L3 超过 120 字符
- 多行 summary、Markdown 标题、代码块、粘贴式命令输出
- L2/L3 使用 `kind=observation`
