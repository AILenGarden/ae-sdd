# 2026-07-03 | ae-sdd v3.8.2 - Task/Project Memory Scope

## Summary

将 Agent 面向的 memory 模型收敛为两个主分区：`task` 与 `project`。底层 L0-L4 仍保留为兼容和生命周期层，但 Agent 默认不再围绕 L1/L2 思考，而是使用 `--scope task` 写任务级记忆，使用 `--scope project` 写跨任务可复用记忆。

## Changes

| Area | Change |
|---|---|
| `tools/lib/memory_store.py` | 新增 `MEMORY_SCOPE_TO_LAYER`：scratch→L0、task→L1、project→L2、pattern→L3、archive→L4；`write/read/search/promote` 支持 scope 参数；记录新增 `memoryScope` 字段；`summarize` 输出 `byScope`。 |
| `tools/bin/ae-sdd` | `memory write/read/search` 新增 `--scope`；`memory promote` 新增 `--from-scope` / `--to-scope`，默认 task→project；保留 `--layer` 兼容旧命令。 |
| `tools/lib/prompt_inject.py` | 注入策略改为 task-first：先取当前 task memory，剩余预算再补 project memory；project memory 不再挤掉 task memory。 |
| `source/skill-fallbacks/skills/cross-cutting/memory-management-skill.full.md` | Agent 指令改为 `--scope task/project`；明确 task 是默认写入目标，project 只存跨任务复用事实。 |
| `source/standards/toolsets/memory-layering.md` | 新增主分区模型：task/project 是 Agent 心智入口，L0/L3/L4 是辅助层。 |
| `tools/tests/test_memory_gate.py` / `tools/tests/test_toolsets.py` | 覆盖 task/project 独立读写、task-first 注入预算、scope promotion 和兼容路径。 |

## Behavior

默认任务级写入：

```bash
ae-sdd memory write --scope task --phase coding --story STORY-001 --kind fix --summary "UserMapper query now filters by tenant_id to prevent cross-tenant reads." --evidence src/main/resources/mapper/UserMapper.xml:31
```

项目级写入必须显式声明：

```bash
ae-sdd memory write --scope project --phase coding --kind constraint --summary "Order amount uses BigDecimal; double/float are forbidden for money math." --evidence source/standards/constraints/code-style.md:42
```

默认 promotion：

```bash
ae-sdd memory promote --phase coding --story STORY-001 --from-scope task --to-scope project
```
