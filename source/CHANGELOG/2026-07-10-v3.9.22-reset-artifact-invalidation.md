# 2026-07-10 | ae-sdd v3.9.22 - Story 重置写入产物作废信号，task-generate 强制全量重建

## Summary

用户提出场景：AgentCoding 过程中发现 Story 有错误，需要回溯到 Story 子系列状态重做。现有机制 `ae-sdd state relocate --story <ID>`（v3.9.0 R5）会调用 `reset_story_substate` 把该 Story 子状态重置到 `story-generated`，但**只重置 phase 指针，不触碰下游产物**。探查发现三条下游 skill 对"产物已存在"的行为不对称：testcase-generate 与 coding-skill/coding-process 的 `save_doc` 无条件覆盖（重跑自动刷新，无风险）；唯独 **task-generate 第三步**有"Task 文档存在 + Story 描述未变 → 跳过；已变 → 增量更新受影响章节"的 prose 判定，且依赖 LLM 文本比对——改了 Story、重置了状态，但 LLM 可能判定"描述没怎么变"→ 旧 Task 的过期章节残留流入下游。本次为 `reset_story_substate` 增加"产物作废信号"（`artifactInvalidated`，挂在 state.json 的 story substate，一次性消费），并在 task-generate 第三步加入最高优先级短路规则：检测到信号则全量新建所有 Task，不再依赖文本比对。flat 模型不补（约定只管 nested）。

## Changes

| Area | Change |
|---|---|
| `tools/lib/state.py` | `reset_story_substate` 重置循环内追加写入 `artifactInvalidated`（含 at/by/scopes/reason），通知下游强制全量重生成；新增 `consume_artifact_invalidation(state, story_id)` helper——读取并一次性清除该 Story 的作废信号（消费即清零防累积），供 skill/gate 调用 |
| `tools/bin/ae-sdd` | `cmd_state_relocate` 重置成功后补一行提示：已写入 artifactInvalidated 信号，下次 task-generate 将强制全量重建 Task（`cmd_state_read` 无字段白名单，新字段天然透传可见，无需改动） |
| `source/skill-fallbacks/skills/phase2-task/task-generate-skill.full.md` | 第三步表格上方插入"🔴 作废优先（强制全量重生成）"最高优先级短路规则：检测到 `artifactInvalidated` 信号则全量新建，优先于"描述未变→跳过"；表格补注脚"仅当无信号时适用本表" |
| `tools/tests/test_nested_state.py` | `TestResetStorySubstate` 新增 3 用例：reset 写入信号且兄弟 Story 不写 / consume 一次性消费（首次返回记录并清除，再次返回 None）/ consume 边界（非 nested、Story 不存在、无信号均返回 None） |

## 触发原因

- 用户担心"状态重定位会做错"，举例 AgentCoding 中发现 Story 错误需退回 Story 子系列重做。
- 根因探查：`reset_story_substate`（state.py:1424）只重置 phase/completedSteps/codingRound 三字段，不清理下游产物。
- 精确收敛：风险面只在 task-generate 第三步的 LLM 文本比对"跳过"分支；testcase/coding 因 save_doc 无条件覆盖本就安全，无需改动。

## 影响范围

- 改变 `reset_story_substate` 写出的 story substate 结构（新增 `artifactInvalidated` 字段），向后兼容——旧代码读 dict 多一个键不影响逻辑。
- task-generate 第三步为 prose 改动，依赖 LLM 遵守短路规则（唯一非确定性环节）。缓解：规则置第三步最显眼位置 + state read 天然可见信号 + consume 设计为"多读安全"（重复全量重生成无副作用）。
- flat 模型（v1 state.json）不受影响——维持现状，relocate 时 warn 跳过（约定只管 nested）。
- 版本号推进：`3.9.21` → `3.9.22`。

## 验证方式

- `python -m py_compile tools/lib/state.py tools/bin/ae-sdd` 语法校验通过。
- `python -m pytest tools/tests/test_nested_state.py -v` → 42 passed（含新增 3 用例全绿，零回归）。
- 行为核对：relocate --story X → storyStates[X].artifactInvalidated 非空、兄弟 Story 为 None；consume 首次返回记录并清零，再次 None；非 nested/不存在/无信号均 None。

## 不做（边界）

- ❌ 不补 flat 模型回溯（用户确认只管 nested）。
- ❌ 不改 save_doc / document_storage / paths（无条件覆盖本就正确）。
- ❌ 不物理删/归档产物文件（用户确认作废标记方案）。
- ❌ 不动 gate_intercept 相位门禁（reset 后 phase=story-generated，门禁自然要求重过 review→testcase→task）。
