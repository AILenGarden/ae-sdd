# 2026-07-09 | ae-sdd v3.9.14 - state 终态投影不变量

## Summary

本次修复 state.json 内两套状态表达静默分裂的问题：`phase/history` 已推进到 `completed`，但 `currentPhase/currentStep/pendingOutputs/codingRound` 仍停在中间步骤。`tools/lib/state.py` 现在在 phase 写入时同步工作流投影字段，并在最终落盘前校验 completed 终态不变量，避免矛盾 state 被持久化。嵌套 state 的 Story 子状态也纳入同一规则，重复写 `completed` 时会修复旧投影但不重复追加 phase history。

## Changes

| Area | Change |
|---|---|
| `tools/lib/state.py` | 新增 `validate_state_invariants()` 与终态校验：`phase=completed` 必须对应 `currentPhase=completed`、`currentStep=completed`、`pendingOutputs` 为空、`codingRound>=r1` |
| `tools/lib/state.py` | `set_phase()` 写生命周期 phase 时级联同步 `currentPhase/currentStep/completedSteps/pendingOutputs/codingRound`，并支持重复 completed 写入修复旧投影 |
| `tools/lib/state.py` | `set_story_substate_phase()` 对嵌套 `storyStates{}` 执行相同投影同步，覆盖 `drStates[*].storyStates{}` 归入模型 |
| `tools/lib/state.py` | `set_current_step()` 改为返回变更状态并容错非 list 的 `completedSteps`；`bump_coding_round()` 兼容 `"r0"` / `"r1"` 字符串旧值 |
| `tools/bin/ae-sdd` | `state write` 捕获落盘不变量错误并以 CLI 错误输出返回，避免 Python 异常堆栈泄漏 |
| `tools/tests/test_state.py` | 增加平面 state 的 completed 投影同步、重复 completed 修复、直接落盘拒绝矛盾 state 的回归测试 |
| `tools/tests/test_nested_state.py` | 增加嵌套 Story 子状态 completed 投影同步与重复 completed 修复回归测试 |
| `source/docs/ae-sdd-design.md` | 补充 state 终态投影不变量的能力语义 |
| `source/docs/ae-sdd-implementation-architecture.md` | 补充 state 写入一致性边界，并修正 `.ae-sdd/state.json` 不再作为 active mirror/fallback 的说明 |

## 触发原因

- 用户反馈 Story-005 处理过程中再次出现状态撕裂：生命周期字段显示已完成，但工作流步骤字段仍处于待人工确认。
- 根因是同一个 state.json 内 `phase/history` 与 `currentPhase/currentStep/completedSteps/pendingOutputs/notes/codingRound` 被不同写入方独立维护，缺少同步契约和终态不变量校验。
- 前序 work-item/session 隔离已解决“全局 state 定位错误”，但未覆盖同一任务 state 内两套字段的终态一致性。

## 影响范围

- 涉及运行时逻辑：`tools/lib/state.py` 的 phase 写入、Story 子状态写入、state 落盘校验。
- 涉及 CLI 行为：`ae-sdd state write --phase completed` 会自动同步投影字段；若其它路径直接尝试落盘矛盾 completed state，会被拒绝。
- 不新增 phase、不改变 `PHASE_FLOWS`、不改变 gate 职责边界。
- 能力设计文档已同步：`source/docs/ae-sdd-design.md` 增加终态投影不变量说明。
- 实现架构文档已同步：`source/docs/ae-sdd-implementation-architecture.md` 增加状态写入一致性边界。
- Monitor 不受影响：没有新增 phase 枚举或路径解析规则；新增/同步的投影字段仍属于原 state.json 原始状态展示范畴。
