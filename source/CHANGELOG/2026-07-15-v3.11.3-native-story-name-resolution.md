# 2026-07-15 | ae-sdd v3.11.3 - 正式 StoryName 原生解析

## Summary

项目正式 Story 文件名可能包含项目前缀、编号、中文标题和端别，不能被强制改成 `{STORY-ID}.md`。此前 G-02/G-14 只按逻辑 ID 查文件，导致 life 的正式 `cs-ai-story-006-门店推荐对接与列表接口-BE.md` 被误报不存在。本次新增显式 StoryName/state 绑定、正文元数据反校验和共享门禁解析器，让正式命名直接可用，同时保留旧 ID-only 文件兼容。

## 触发原因

- life 项目正式 StoryName 无法通过 G-02，工具错误要求创建 ID-only 别名文件。
- 同一逻辑 `STORY-006-BE` 在多个项目文档中存在，模糊 ID 扫描会产生不可接受的错选风险。

## 影响范围

- 改变 Story 文档读取、G-02/G-14 和 state CLI；不改变逻辑 Story ID、R6 stateMachineName 或正文存放位置。
- 向后兼容 `{STORY-ID}.md`；正式命名项目需要执行一次显式绑定，不存在自动模糊迁移。
- 版本推进到 3.11.3；无破坏性 schema 迁移，新增 state 字段为可选字段。
