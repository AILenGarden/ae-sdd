# 2026-07-11 | ae-sdd v3.10.1 - Review Batch 与 Story 模板去重

## Summary

Story-003 的长耗时复盘显示，固定 round/dryCounter 会把有效 reviewer、平台失败、输入漂移和历史债务混在一起，造成重复验证与无法终止。本次加入 Review Batch v2、G-CODE-1 增量 baseline、变更感知 VerificationPlan、evidence manifest/cache 和 canonical 文档 alias；同时修订 Story 主模板，建立撰写原则并消除错误码、状态展示和 ①bis 自检的强制重复。

## 触发原因

- Story-003 实战中平台 429、reviewer 集不完整和输入变化不能被可靠区分，连续 clean 计数不代表有效复核。
- G-CODE-1 对全仓历史 debt 重复收费，缺少显式 baseline 与 Story delta 语义。
- Maven/扫描/测试证据没有 content-addressed 复用条件，文档路径存在 canonical/兼容双写风险。
- Story 模板把同一规则放入多个必填章节，Review 成本随文档长度增长。
- Review Batch 的平台重试必须回填原 batch；baseline 篡改和 touched debt 必须显式阻断；缓存证据必须受 freshness window 约束。

## 影响范围

- 运行时：review-loop state schema 增加 v2 字段；旧 state 可读并会导入为未验证 legacy batch，不伪造 valid clean。
- 门禁：存在完整且未篡改 baseline 时，G-CODE-1 可返回 `PASS_WITH_BASELINE_DEBT`；新增 blocker 或 touched debt 仍阻断。
- 文档：Story 新模板的章节职责变化只约束新建/重大修订 Story；旧 Story 不自动迁移。
- 分发：新增模块通过现有 `build_dist.py`/`install.py` 进入编译包；不手改 `dist/` 或已安装副本。
