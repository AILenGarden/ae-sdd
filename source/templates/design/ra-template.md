```mermaid
      风险 2：{描述}
```

> 示例（账号登录失败 5 次锁账号）：

```mermaid
mindmap
  root((账号登录失败 5 次锁账号))
    业务背景
      C 端用户被撞库风险高
      现有方案：密码复杂度 + 验证码
      缺失：账号锁定机制
    核心角色
      C 端用户：被锁定后无法登录
      客服：协助解锁 + 工单处理
      安全运营：审计 + 监控告警
    关键场景
      主流程：5 次失败 → 锁定 30 分钟
      解锁：自助 / 管理员
      衍生：T 下线 / CS Away / IM Offline
    核心数据
      User.status：Normal/Locked
      LoginAttempt：失败次数 + 时间
    关键决策
      锁定时长：30 分钟（折中）
      衍生策略：12 个方向穷举
    关键风险
      风控误判：合法用户被锁
      跨域级联：T/CS/IM 同步
```

**绘制原则：**
- 第一层（root）：**需求名称**（一句话）
- 第二层：6 个固定类别（业务背景 / 核心角色 / 关键场景 / 核心数据 / 关键决策 / 关键风险）
- 第三层及以下：每个类别下放 3-7 个要点，**禁止超过 10 个**（多了就太杂）
- 禁止写完整句子（mindmap 是关键词 + 短句，不是叙述）
- 颜色 / 样式不需要配置（Mermaid 默认即可）
