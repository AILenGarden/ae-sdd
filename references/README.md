# 参考文献目录

本目录用于沉淀 ae-sdd 维护、设计、工程实践、自动化流程、AI Agent 协作等主题的参考资料索引。

这里优先保存“可追溯的引用信息”和“与 ae-sdd 相关的摘记”，不要直接提交受版权保护的完整书籍、论文原文、课程材料或付费内容副本。

## 目录结构

```text
references/
├── README.md        # 本说明
├── papers/          # 论文、技术报告、白皮书
├── books/           # 书籍、章节、公开阅读笔记
├── articles/        # 博客、工程文章、公开网页
├── standards/       # 标准、规范、协议、官方文档
└── cases/           # 案例研究、复盘、经验材料
```

## 收录原则

- 资料必须与 ae-sdd 的方法论、流程门禁、测试真实性、代码审查、Agent 编排、文档治理或工程自动化直接相关。
- 每条引用必须能追溯来源，至少包含标题、作者或组织、发布日期或访问日期、链接或出处。
- 优先记录一手来源，例如官方文档、论文页、标准正文、项目仓库、作者原文。
- 对网页类资料记录访问日期，避免链接内容后续变化导致引用失真。
- 对本地摘记只保留必要摘要、关键结论和个人评注；不要大段复制原文。

## 命名规则

建议使用以下文件名格式：

```text
YYYY-MM-DD-short-title.md
```

示例：

```text
papers/2026-07-02-agent-workflow-verification.md
standards/2026-07-02-openapi-contract-review.md
articles/2026-07-02-test-authenticity-practice.md
```

如果资料没有明确发布日期，使用首次收录日期。

## 维护约束

- 不把未经授权的 PDF、电子书、课程资料、付费文章全文提交到仓库。
- 不把二手转述当作权威依据；二手资料需要标注“转述”并尽量补一手来源。
- 过期资料不直接删除，优先在文件中标注“已过时”并说明替代资料。
- 如果资料已经转化为 ae-sdd 的标准、模板或 SKILL 规则，应在对应文档中反向链接本目录下的引用记录。
