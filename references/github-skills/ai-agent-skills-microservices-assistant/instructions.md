# Instructions for Using the AI Agent

## For Team Members
1. **Setup**: Clone repo; open in VS Code/Claude.
2. **Querying AI**:
   - Copilot: "// [Agent]: Load [skill-name] for [task]". Paste prompt.
   - Claude: "You are the microservices agent from agent.md. Load [skill-name]: [paste]. Now, [query]."
3. **Code Review**: Use templates/code-review-template.md.
4. **Extending**: Add skills with skill.md template.
