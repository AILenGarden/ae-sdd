# 模板排版规范化工程 — 22 个模板统一 10 类排版规范

## 一、目标

用户反馈："模板不仅仅要约束内容，还要约束格式、字体大小、表格样式"。经三组 Explore agent 扫描全部 22 个模板，发现 10 类系统性排版缺陷。本次按用户选定方案全面规范化：
- **范围**：全部 10 类问题
- **标记体系**：反引号 `` `必填` `` / `` `选填（...）` ``
- **编号体系**：阿拉伯数字 `## 1.` / `### 1.1`

## 二、排版规范 SSOT（先建标准，再套用）

**新建 `source/standards/templates/template-layout-standard.md`**（模板排版规范 SSOT），定义 10 条规则：

| # | 规则 | 规范 |
|---|------|------|
| 1 | **必填/选填标记** | 标题尾部反引号：`` `必填` `` / `` `选填（条件）` `` / `` `🔴 强制` ``。禁止 `（🔴 必填）` 全角括号、`[已确认]` 方括号、`核心`/`按需` 等其他词汇 |
| 2 | **表格分隔符** | 统一 `| --- |` 带空格（每列前后各一空格），禁止 `|------|` 紧凑无空格 |
| 3 | **章节分隔线** | 每个 `##` 二级章节之间用 `---` 分隔；文档末尾不收尾 `---`（最后一章后直接结束）|
| 4 | **占位符** | 统一 `{占位符}` 花括号；禁止 `<>` 尖括号、`（）` 全角括号、`XXX`、`待填写` |
| 5 | **章节编号** | 纯阿拉伯数字 `## 1.` / `## 2.`，子节 `### 1.1` / `### 1.2`；禁止中文数字"一、二"、`§N`、小数子章"1.5"（除非确有 1.1-1.4）、父阿拉伯+子中文混搭 |
| 6 | **示例引导** | 统一 `> 示例：` 引用块引导；禁止 `**填写示例：**` 加粗、集中附录（除非示例跨多节）|
| 7 | **强制规则锚点** | 统一 `> **🔴 强制：**` 引用块 + 加粗；禁止 `**红线：**` 非引用、`> **强制规则**：` 不带 emoji、`> - 🔴` 列表项 |
| 8 | **emoji 语义** | 🔴=阻断/强制、🟠=严重、🟡=一般、🟢=建议/通过、✅=完成、❌=失败、⚠️=警告、🆕=新增。同一语义全模板统一同一 emoji |
| 9 | **文档头部声明** | 统一格式：H1 标题 → `>` 引用块含"适用场景"+"精简规则"（可选"集成规范"）。project-assets 类模板补"适用场景"引导语 |
| 10 | **末尾收尾** | 最后一章后不加 `---`（文档自然结束）；frontmatter（如有）保持 YAML 格式 |

## 四、执行策略（并行加速）

22 个模板改动是模式化重复，按层分组派 sub-agent 并行处理：
- **派 1 个 sub-agent** 处理 design 类重改 5 个（dr/ra/be-story-review/be-task-impl/story-generate-plan）
- **派 1 个 sub-agent** 处理 design 中改+轻改 6 个（prd/prd-summary/issue/story-writer/story-template 微调/be-task）
- **派 1 个 sub-agent** 处理 coding+testcase 5 个
- **派 1 个 sub-agent** 处理 project-assets+proposal+skill 7 个
- **主会话**：建 SSOT 标准文档 + 版本号 + CHANGELOG + 最终验证

每个 sub-agent 拿到统一的《排版规范 SSOT》+ 分配给它的模板清单，按规则逐文件套用。

## 五、关键风险与规避

| 风险 | 规避 |
|------|------|
| **重编号 break 代码解析** | 已确认 `gates.py:2537` 只依赖"标题含'接口契约'字样"不依赖编号数字；`review_loop.py:371` 只用维度名不用编号。重编号安全 |
| **slim-entry 模板是生成器产物** | `source-skill-slim-entry-template.md` 是生成器模板（被 `slim_source_skills.py` 渲染），改动需同步生成器逻辑。**降级处理**：仅改占位符 `<>`→`{}` 和头部声明，不改结构 |
| **22 个模板改动量大导致遗漏** | 每个模板改完后跑一次 `grep -c` 自检（分隔符/占位符/标记），最后全局 grep 扫描 |
| **编号体系统一后影响文档间交叉引用** | 部分文档用 `§D` / `§F` / `§六` 等引用章节，重编号后需同步更新引用。grep 扫描 `§[A-Z一-龥]` 找出所有章节引用 |

## 六、验证方式

1. `python tools/bin/ae-sdd update-check`：UC-01 版本号一致性全绿
2. `python tools/tests/run.py`：全部测试通过（重点 test_context_gates 不回归）
3. 全局 grep 扫描：
   - `grep -rn "|---|\||----|\||-----|\||------|" source/templates/` → 应为 0（所有分隔符带空格）
   - `grep -rn "（🔴 必填）\|（🔴 维度\|\[已确认\]" source/templates/` → 应为 0
   - `grep -rn "<[A-Za-z]" source/templates/` → 应为 0（无尖括号占位符，HTML 标签除外）
   - `grep -rn "## §\|## 一、\|## 二、" source/templates/` → 应为 0
4. 人工抽查 3 个模板确认渲染效果

- SKILL 文档（source/skills/）和 standards 文档（source/standards/）的排版：本次只管 templates/，SKILL/standards 排版是另一回事
