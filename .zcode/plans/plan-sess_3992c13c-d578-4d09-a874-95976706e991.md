# ae-sdd v3.10.0：砍 Task Phase + Route 下移重分级

## 目标

将 ae-sdd 流程从 `Story -> TestCase -> Task -> Coding -> Test -> Review` 精简为 `Story -> TestCase -> CodingPlan -> Coding -> Test -> Review(含实现报告)`，并重新定义 4 级 route。

## 一、核心改动：从所有 phase 链中移除 Task

### 1.1 `tools/lib/state.py` — PHASE_FLOWS（:80-105）

当前 4 条链均含 `task-generated -> task-reviewed`。新链移除这两个 phase：

| scale | 入口 | 新 phase 链 | 相位数 |
|-------|------|------------|--------|
| **大** | DR | `initialized -> dr-generated -> story-generated -> story-reviewed -> testcase-generated -> testcase-reviewed -> coding-process -> coding -> test-running -> code-reviewed -> completed` | 11 |
| **中** | Story | `initialized -> story-generated -> story-reviewed -> testcase-generated -> testcase-reviewed -> coding-process -> coding -> test-running -> code-reviewed -> completed` | 10 |
| **小** | CodingPlan | `initialized -> coding-process -> coding -> test-running -> code-reviewed -> completed` | 6 |
| **微** | 无文档 | `initialized -> coding-process -> coding -> test-running -> code-reviewed -> completed` | 6 |

> **大链不含 `ra-generated`**：用户明确"大从 DR 出发"，RA 降为前置条件（G-RA 门禁检查 RA 文档已存在），不在链内生成。requirement-analysis-skill 保留为独立 skill，不进主流程链。

### 1.2 `tools/lib/state.py` — _NEXT_STEP_MAPPINGS（:396-451）

4 条子链同步移除 `task-generated`/`task-reviewed` 节点。关键变更：
- `testcase-reviewed` 的 next 从 `task-generated` 改为 `coding-process`（大/中链）
- `initialized` 的 next 在小链改为 `coding-process`（原为 `story-generated`），微链改为 `coding-process`（原为 `task-generated`）
- `coding-process` 的 action 描述更新为"加载 Story+TestCase 上下文 + CodeAnalysis + 出统一 CodingPlan（含骨架分解）"

### 1.3 `tools/lib/state.py` — _infer_scale（:155-188）+ docstring（:46-54）

反推逻辑下移对齐：`has_dr -> 大`、`has_story(无dr) -> 中`、`has_coding(无story) -> 小`、默认 -> 大。docstring 更新 4 链描述。

### 1.4 `tools/lib/state.py:112` — PHASE_FLOW 别名

`PHASE_FLOW = PHASE_FLOWS["大"]` 仍指向大链（deprecated 别名），无需改动（大链仍是最完整链）。

## 三、Route 分级下移

### 3.1 `tools/bin/ae-sdd` — _default_scale_for_state_new（:355-365）

当前映射：`DR->中, STORY->小, TASK/BUG->微, default->大(PRD)`。
新映射：

```python
if marker in {"BUG", "OPT", "CONFIG"} or ...: return "微"   # 无文档
if marker == "STORY": return "中"                              # Story 入口
if marker == "DR": return "大"                                 # DR 入口
# 新增：已有 Story+TestCase 且用户要求直出 CodingPlan -> 小
if marker == "PLAN": return "小"                               # CodingPlan 入口
return "大"  # default
```

### 3.2 `tools/bin/ae-sdd` — entry_node 推断（:413-423）

`PRD-` 前缀不再映射为独立入口（PRD 层已弃用）。`DR-` -> DR(大), `STORY-` -> STORY(中), 其余 -> 视上下文判定小/微。

### 3.3 `tools/lib/classify.py` — _infer_scale_from_project_context（:149-251）

| 已有产物 | 新 scale | 旧 scale |
|---------|---------|---------|
| RA doc 存在 + blockingGaps≥5 | 大 | 大 |
| Story doc 存在（design/） | **中** | 小 |
| 无 Story 但有 TestCase | **小** | (无) |
| 无任何文档 | **微** | (无) |

### 3.4 `tools/lib/flow_enums.py` — FlowNode + is_nested_entry（:29-78）

`FlowNode.PLAN`（:48，已存在，"微任务/CodingPlan 直出"）语义更新为"小任务 CodingPlan 入口"。`is_nested_entry` 保持 PRD/DR/STORY 为 nested。
