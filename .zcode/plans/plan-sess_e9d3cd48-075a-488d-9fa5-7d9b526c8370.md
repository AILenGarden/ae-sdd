# ae-sdd L2 会话级纪律 SSOT 化 + 分发注入

## 背景与目标

当前 ae-sdd 纪律分两层：
- **L1（CODING ENTRY CONTRACT）**：只活在 `source/HARNESS.md:28-47`，已随 distribute.py 分发到三家 skill runtime，**已对齐**。触发语义已是"改动级加载"（第 32 行"在制定实现计划或首次写入前加载"）。
- **L2（会话级纪律）**：散落在三家全局指令文件（ZCode/Codex/Claude），各自手写、措辞分化、无锚点、不在分发链内。**已漂移**：
  - ZCode：最强（"首轮必须 /ae-sdd"+"无例外"）+ 最完整纪律段
  - Codex：中等（英文，触发语义已对齐"改动级加载"，但缺 SDD+TDD/四上下文/非仓库判定展开）+ 独有 fail-closed/反作弊/quick 通道强约束
  - Claude：最弱（"只需触发一次"软化版 + 缺红线条款 11 + 缺执行纪律整段）

**目标**：把 L2 提升为 ae-sdd 自持的 SSOT，经 distribute.py 按 agent 适配注入到三家全局文件锚点区，根除漂移。统一触发语义为"改动级加载"（与 L1 一致）。

**核心安全约束（用户强调）**：注入只动 ae-sdd 锚点区间，绝不触碰各 agent 全局文件的其余原有内容（红线表、技术栈、Thinking Engine、Sync Discipline 等）。

## 三、注入器：新增 `scripts/l2_inject.py`

纯 Python（与 distribute.py 同栈，零外部依赖），复用 harness-adapter 的四件套设计（幂等/diff-aware/备份/审计），不复用其转译业务。

### 锚点格式（Markdown 三家通用 HTML 注释）

```markdown
<!-- BEGIN ae-sdd-l2-ssot @ <commit> @ <ts> -->
...SSOT 渲染内容（按 agent 语言）...
<!-- END ae-sdd-l2-ssot -->
```

### 核心逻辑

1. **读 SSOT**：`source/L2-DISCIPLINE.md`，按 `l2_language` 切片中/英文段。
2. **渲染**：按 agent 语言组装锚点区间内容（含审计头 + 红线条款 11 的语言版本）。
3. **diff-aware skip**：计算 SSOT 内容 hash + 适配版本号；若目标锚点区间内现有 hash 与之一致，skip（幂等）。
4. **锚点存在 -> 区间替换**：定位 `BEGIN`/`END` 锚点，**只替换锚点之间内容**，锚点外字节零改动。
5. **锚点不存在 -> bootstrap 模式**（见下节，需人工确认）。
6. **备份**：注入前 `cp <global_file> <global_file>.bak.<ts>`（保留最近 3 份）。
7. **落盘后校验**：读回文件，断言锚点外区域的字节与备份完全一致（用 difflib 对比锚点外行），不一致则回滚并报错。

### Bootstrap 模式（首次锚点落盘，高风险）

三家当前都无锚点，且各自有手写的 ae-sdd 段落。bootstrap 不能自动跑，流程：

1. **识别现有 ae-sdd 段落边界**：按标题模式匹配：
   - ZCode：`## ae-sdd 工作流强制调用（git 仓库下）` 到 `## ae-sdd Coding 执行纪律...` 段末（下一个 `---` 或 `## 设计原则`）
   - Codex：`## Mandatory ae-sdd Coding Workflow` 段
   - Claude：`## ae-sdd 工作流调用（git 仓库下）` 段
2. **dry-run 预览**：`python scripts/l2_inject.py --bootstrap --dry-run` 输出"将替换的行范围 + 前后 diff 预览 + 锚点外零变更断言"。
3. **人工确认**：用户审 diff 后 `--bootstrap --apply` 落盘。
4. **红线条款 11 特殊处理**（Claude）：Claude 红线表现在 10 条，bootstrap 时在条款 10 后插入条款 11 行 + 同源注释。此操作在锚点区外，**单独标记为"红线补丁"**，需在 dry-run 里明确高亮，且仅 Claude 需要。

### 命令行接口

```
python scripts/l2_inject.py                    # 常规注入（已 bootstrap 的 agent）
python scripts/l2_inject.py --target claude    # 指定单 agent
python scripts/l2_inject.py --bootstrap --dry-run   # 首次落盘预览
python scripts/l2_inject.py --bootstrap --apply     # 首次落盘执行
python scripts/l2_inject.py --rollback <agent>      # 回滚到最近备份
```

## 五、安全保障（用户核心关切）

| 保障 | 机制 |
|---|---|
| **锚点外零改动** | 注入器只替换 `BEGIN`/`END` 之间内容；落盘后用 difflib 校验锚点外行与备份字节一致，不一致回滚报错 |
| **bootstrap 人工确认** | 首次落盘必须 `--dry-run` 审 diff + `--apply` 确认，不在 post-commit 自动跑 |
| **备份可回滚** | 每次注入前 `.bak.<ts>`，保留最近 3 份，`--rollback` 可恢复 |
| **diff-aware skip** | SSOT hash 未变则跳过，避免无意义重写 |
| **Codex Sync Discipline 不破坏** | Codex `AGENTS.md:27-30` 的 Sync Discipline 段在锚点区外，注入器不触碰 |
| **红线补丁单独标记** | Claude 条款 11 补丁在锚点区外，dry-run 高亮，仅 Claude 需要 |
