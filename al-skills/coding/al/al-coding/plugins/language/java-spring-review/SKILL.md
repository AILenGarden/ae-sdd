# java-spring-review — Java + Spring Boot 评审适配器（review 能力）

> **定位：** 叠加于 `core/review-core.md` 之上的 Java/Spring 语言特化层。只提供 Java/Spring 的具体检查命令、证据形态与反模式；通用评审维度和证据分类以 Review Core 为准。静态扫描复用 `plugins/language/java-spring-coding/SKILL.md §12`（引用不复制）。

## Java 结构与事务判据

配合架构插件的红线表使用（红线归属见架构插件；本节只给**可执行判据**）：

| 检查 | 命令/判据 | 反模式 |
|------|----------|--------|
| 存取语义（B1） | 按架构适配器定义的存取组件范围，逐个列出方法并判语义 | `handleXxx`/`processXxx`/含业务 if 分支 |
| 领域组件纯净（B4） | 在架构适配器标记的领域目录中扫描 Java 持久化注解与对象导入，期望为空 | 领域组件出现持久化对象或具体持久化注解 |
| 事务边界 | 事务声明位置遵循架构适配器的落点；方法内无远程调用或消息发送 | 事务内进行网络调用或发送不可回滚消息 |
| 异常体系 | `grep -rn "throw new RuntimeException\|throw new Exception" src/main/java/` 期望为空 | 裸异常、无错误码 |

## 持久化规则引用

| 维度 | 评审责任 |
|------|---------|
| 数据模型与审计字段 | 以项目插件/约束文档为准；本插件只核对代码是否遵守已声明契约 |
| 删除、分页与锁 | 以项目插件/约束文档为准；不得把某一种字段名、分页组件或锁条件当作 Java 通用规则 |
| 参数绑定 | 由项目声明的持久化适配器提供具体语法；本插件只要求不存在未审查的字符串拼接或未参数化输入 |
| 外键与级联 | 以项目数据模型和迁移约束为准；本插件不预设是否允许数据库级联 |

> 若项目未提供持久化约束，评审必须将该维度列为未解析，而不是套用某一种持久化框架的默认规则。

## Java 测试证据形态

| 必查项 | 证据形态 |
|--------|---------|
| 单测执行 | `target/surefire-reports/*.xml`（含 tests/failures/errors 计数） |
| 集成测试 | `target/failsafe-reports/*.xml` |
| 跳测检测 | grep 命令行与 pom：`-DskipTests` / `-Dmaven.test.skip` / `testFailureIgnore` / `maven.test.skip=true`，任一出现 = 虚报成功（🔴，对照 CodingModel 测试有效性判定） |
| 执行数对账 | XML 实际执行数 ≥ 方案声明的用例数；少于声明且无解释 = 假修复风险 |
| 真实环境 | 涉及外部数据源或网络边界的用例：确认测试类启动项目要求的真实环境，非纯 Mock |

## 静态扫描复核

评审时重跑 `java-spring-coding §12` 三类扫描（命令见该插件，不在此复制）；任一命中都要关联具体规范条目、触发条件和实际影响，按 Review Core 的严格结论和严重度输出。
