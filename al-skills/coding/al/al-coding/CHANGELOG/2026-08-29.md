# ALCoding 变更历史

## 2026-08-29

- 重构注册边界：ALCoding 现在只负责登记和索引 SKILL，不解析、改写、合并或执行注册的 SKILL 正文。
- 注册表改为 `schema_version: 2` 的 `skills` 表，使用 `id`、`name`、`type`、`path`、`enabled` 及可选发现元数据。
- 移除注册协议中的 capability/matches/versions/priority/overlays/extends/依赖和外部路径信任判定；这些不再属于注册器职责。
- 新增 `scripts/registry.py` 输出按 global/language/architecture/project 分组的能力索引；`validate_plugins.py` 只校验注册元数据和 id/name 唯一性。
- 新增注册表回归测试，覆盖禁用项、重复身份和任意格式的作者 SKILL。
- `scripts/registry.py` 增加 `register/update/remove/enable/disable/show/list` 注册器命令，注册表写入采用临时文件加原子替换，并声明 PyYAML 依赖。
