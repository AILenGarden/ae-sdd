# ALCoding 变更历史

## 2026-08-30

- 注册器脚本完成命令化：支持 `register/add`、`update`、`remove/unregister`、`enable`、`disable`、`show` 和 `list/ls`。
- 注册和更新在写入前重新校验候选注册表，重复身份或非法元数据不会落盘。
- 注册表写入使用同目录临时文件、`fsync` 和原子替换，且不会读取或修改被注册的 SKILL 正文。
- 索引支持本地文件与 URI/reference 两种登记值，并明确 `reference_kind` 与 `available` 状态。
- 补充注册 CLI、重复名称归一化、坏注册表拒绝和 URI 引用的回归测试。
- 新增本地注册 UI 与启动器，支持上传 SKILL、填写四类登记信息、修改、启停和取消注册；上传内容按原字节保存，不解析正文。
