# ALCoding 0.3.2 - Context Loading Contract

## Changes

- Expanded the entry SKILL with an explicit project-context loading sequence.
- Standardized the specification context label as `Spec——需求、PRD、DR、Story 或任务说明`.
- Added a pre-edit context manifest and gate covering repository scope, selected
  core and registered SKILLs, package semantics, naming, enum/constant sources,
  unknowns, conflicts, and verification evidence.
- Clarified that supplementary SKILL selection is evidence-based Agent
  reasoning; ALCoding does not auto-match, merge, override, or execute authors'
  SKILL content.
