# ALCoding 0.3.3 - Registration Scope

## Changes

- Added the independent registration scope `global` or `project`.
- Added required `project_id` validation for project-scoped entries.
- Added project-aware index filtering while keeping scope separate from the
  existing capability category (`type`).
- Updated the CLI, loading contract, entry Skill, and registry specification
  with project-scoped registration examples.
- Kept scope as an eligibility filter only; ALCoding does not add implicit
  precedence, merging, or override behavior.
